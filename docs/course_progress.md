## Tracking Rules

1. **Allowed statuses:** `Not Started`, `In Progress`, `Completed`, `Blocked`.
2. Use `YYYY-MM-DD` for completion dates.
3. Only mark a lesson `Completed` after its deliverable is implemented and verified.
4. Leave the completion date as `—` until the lesson is completed.
5. Update the progress overview whenever a lesson's status changes.
6. Append notes under the corresponding lesson heading.
7. Preserve previous notes when revisiting a completed lesson.
8. Reference GitHub commits or pull requests when useful.
9. The GitHub repository is the single source of truth for progress.
10. Keep this file synchronized with [course_plan.md](course_plan.md).
